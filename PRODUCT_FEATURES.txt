NetPulse 核心功能与特性清单 (v1.2.0)
=====================================

一、界面设计与交互体验 (UI & Interaction)
----------------------------------------
1. 现代化 Fluent Design 界面
   - 遵循 Windows 11 设计规范，采用圆角 (Rounded Corners)、阴影 (Shadows) 和深度感。
   - 支持"亚克力" (Acrylic) 材质与"云母" (Mica) 材质背景，营造半透明与磨砂玻璃的视觉效果。
   - 提供明亮 (Light) 与深色 (Dark) 两套无缝主题切换。

2. 双语支持 (Bilingual)
   - 原生支持简体中文与 English 双语界面。
   - 可跟随系统语言自动切换，也可在设置中手动选择。

3. 流畅的视觉反馈
   - 所有按钮、卡片均带有平滑的过渡动画与悬停态。
   - 数据图表实时更新，支持交互式缩放与滚动。

二、核心功能模块 (Core Modules)
--------------------------------
1. 压力测试引擎 (Stress Test Engine)
   - **多目标并行测试**：支持同时对多个网站/IP 发起压力测试，实时聚合展示每个目标的状态。
   - **多协议支持**：HTTP、HTTPS、TCP、UDP、ICMP（Ping）。
   - **精细控制**：可调节并发线程数、请求速率上限（QPS）、持续时间等参数。
   - **实时统计面板**：
     - 实时 QPS (Queries Per Second) 监控。
     - 成功/失败请求数与实时错误原因分析。
     - 累计发送流量统计（自动换算 B/KB/MB/GB）。
     - 活跃线程数监控。
   - **专业级报告**：测试结束后生成详细报告，包含平均延迟、P50/P90/P99 分位延迟、错误类型分布等。
   - **配置导入/导出**：可将测试配置保存为 JSON 文件，下次直接导入复用。

2. 实时系统监控 (Real-time System Monitor)
   - 实时监控本机 CPU、内存、网络吞吐等性能指标。
   - 直观的动态折线图与柱状图，支持缩放与历史回溯。

3. 分布式协同测试 (Collaborative Testing)
   - 支持多节点协同发压，模拟更高并发压力。
   - 通过公共 MQTT 中继服务器实现外网协同，无需自建服务器。
   - 邀请码机制快速建立主控-节点连接，支持 5 分钟有效期。

4. 授权与合规 (Authorization & Compliance)
   - 内置授权确认机制，所有目标需经过用户授权方可测试，确保合法合规。
   - 内置速率与流量保护机制，防止误操作。

三、实用工具与功能 (Utilities)
-------------------------------
1. 自动检查更新 (Auto Update)
   - 启动时静默检查 GitHub Releases。
   - 发现新版本时弹窗提示，一键跳转至发布页下载。

2. 审计日志 (Audit Logging)
   - 完整记录所有压测操作历史，支持导出为文本文件，便于复盘与审计。

3. 应用设置 (Settings)
   - 个性化配置：主题、语言、默认测试参数（线程数、超时、速率等）。
   - 关于页面：显示版本信息、免责声明、作者主页链接。

四、技术亮点 (Technical Highlights)
----------------------------------
- 基于 Python + PySide6 (Qt) 构建，性能与跨平台兼顾。
- 独立的多线程压力测试引擎，UI 响应流畅不卡顿。
- 数据本地持久化，重启后自动恢复上次测试配置。
- 公共 MQTT 中继实现零配置外网协同测试。
